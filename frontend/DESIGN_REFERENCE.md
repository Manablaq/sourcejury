# Visual reference

The requested Magnific sport landing-page template is used as a visual-direction reference:
high-energy editorial composition, oversized athletic typography, strong diagonal/motion cues,
high-contrast dark surfaces, bright accent blocks, and a hero that feels active rather than corporate.

This implementation recreates that visual grammar as an original SourceJury interface. It does not
redistribute the referenced stock/vector asset.

SourceJury-specific adaptation:
- evidence cards replace sports product cards;
- consensus orbit replaces the athlete/product hero image;
- acid yellow and electric blue create an energetic court identity;
- scroll reveals and moving evidence tape provide motion while respecting reduced-motion settings;
- documentation and live contract state remain first-class product surfaces.
